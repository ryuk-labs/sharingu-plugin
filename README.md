# sharingu — the plugin

The sharingu plugin for Claude Code and compatible clients. Installs free; the hosted service (https://www.sharingu.xyz) is the product.

```
claude plugin marketplace add ryukdev/sharingu-plugin
claude plugin install sharingu@sharingu
```

Proprietary — © Ryuk Labs. This repository holds only the plugin (no engine code) and is synced from the private engine repo.
